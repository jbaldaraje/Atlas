This is an expanded development implementation spanning phases 1–6. It is **not a completed production release**. Native source has not yet been compiled or run; static parsers cannot check framework API compatibility or runtime correctness.

No external cloud service or API key is required. No mock files/statistics are injected. Local excerpts and word-frequency tags are labeled as such rather than represented as AI-generated summaries. An image OCR request is explicit. Automatic monitoring never extracts contents.

The next decisive step is execution on macOS. The new GitHub Actions workflow can run unsigned builds, package tests, and filesystem/encryption tests on repository pushes and pull requests. It does not replace signed sandbox, permission, visual/accessibility, or authentication testing, and it has not run from this chat. Source changes have been pushed during development; no release or successful CI outcome is asserted.

Incremental smart scanning now adds shared Overview/sidebar entry points, multi-source pre-scan presets, real EXIF date/GPS opt-in organization, evidence-backed topic/group memberships in the existing graph, persisted progress/results and retry, and filesystem-identity catalog merges. See SmartScanning.md for the exact scope and file inventory. The native build/test gate remains open; unsupported Office content, photo similarity, reverse geocoding, and semantic project inference are not claimed.

Manual scans now count selected files before processing and show estimated completed/remaining percentages with a cinematic loading view. The modal can be minimized while the application-owned job continues; a persistent status bar offers expand/cancel/results. Completion does not reopen a minimized modal. This works while Vault is open and does not implement a daemon or exact traversal continuation after quitting; journaled stopped jobs can be retried safely. See ScanProgress.md for semantics and pending macOS validation.

Knowledge Map now uses an actor-backed cached graph index and bounded published projections (150 nodes / 900 visible edges), searchable paging across the full catalog, action-time file lookup, cancellation, loading states, and separate asynchronous layout persistence. Opening the map no longer performs per-node catalog searches or saves the full workspace. These address source-level hotspots visible in the supplied debugger screenshot; actual latency/memory improvements and the reported repeated-update warning still require macOS validation. See KnowledgeMapPerformance.md.

Ordinary file-heavy workspaces now use parent/group-first navigation with 60-child pages and a shared background catalog index. Subjects link files through folder navigation; timeline event/month parents and Notes account/folder parents delay child rendering. Overview, storage, recovery, and inspector long lists are also collapsed or paged. Thumbnail requests use a bounded active queue and cancellation. This is a source implementation pending native compilation, Quick Look validation, performance measurement, and accessibility acceptance; existing JSON persistence remains a separate cost. See FolderBrowsing.md.

A shared persistent All Types / Docs / Media / Photos selector now filters file workspaces, graph projections, storage results, and recovery records before paging. Counts reflect matching files; scan categories remain independent. Storage/recovery preparation stays in background tasks, and typed graph/filter queries reuse existing indexes. Source/test updates are present, with native compilation, accessibility, persistence, and runtime validation still pending. See FileTypeFilters.md.

Connected exploration now extends the existing inspector and reader with source-grounded At a Glance, explainable related-document paging, optional indexed-text suggestions, review/dismiss/link removal, topic routes, compact persistent history, native PDF find, and shared map context with retained positions. Overview adds eight optional customizable quick-access widgets, bounded real data, existing viewers, actual note/default-app access activity, collection pins, and separate atomic preferences. The old inspector link list is integrated into the connected panel. See ConnectedExplorerDashboard.md for the complete inventory and limitations. Native compilation, PDFKit/Quick Look runtime behavior, signed permissions, accessibility, multiwindow behavior, and measured performance still require macOS acceptance; these features do not establish production readiness.

Menu bar mode now provides a single reusable workspace, graph/search/scan routes, cooperative pause/resume/cancel, quiet optional scan alerts, visibility-based resource suspension, power/sleep handling and orderly quit. Monitoring is event-driven instead of periodic full-root polling. Separate job journals, background scan encoding, unchanged reference/hash reuse, bounded text/OCR/thumbnail work and cache eviction address source-level costs. Native build, lifecycle behavior, Instruments measurements, and the existing synchronous persistence/Notes Automation bottlenecks remain unverified or unfinished. See RuntimePerformance.md.
